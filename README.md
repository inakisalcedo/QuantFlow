# 🌊 QuantFlow

**QuantFlow** is a Python library designed for analysts and traders who want to centralize critical crypto-market and macroeconomic metrics without relying on expensive premium API subscriptions.

Built with an "API-Key Free" philosophy, the library aggregates data from open sources to calculate sentiment and macro indicators.

## 🚀 Key Features

* **Sentiment:** Integration with the Fear & Greed Index.
* **Derivatives:** Global Open Interest (OI) history via CCXT.
* **Macro:** Connection with FRED for GDP.
* **Market:** Bitcoin Price History.
